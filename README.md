# Shotlister Studio — downloads

Shotlister Studio is a personal shot-listing app for one cinematographer. It is
not for sale, not supported, and not open source; this page exists so one Mac
can hand a finished copy to another.

**To install it:** open the [latest release](../../releases/latest), download the
`.dmg`, and drag Shotlister Studio into your Applications folder. From then on
the app offers its own updates and there is nothing to come back here for.

`appcast.xml` is the list of published versions that the app reads to know
whether it is out of date.
